## 목적

기존 원본으로 Three.js용 GLB 파생 자산을 제작하고 검증한다.
전륜 조향과 바퀴 굴림은 구현하지 않으며,
향후 object transform으로 제어할 수 있는 구조만 준비한다.

적용되는 AGENTS.md와 실제 파일을 먼저 확인한다.
원본 선택 이유를 기록하고 원본은 수정하거나 덮어쓰지 않는다.
기존 결과가 있으면 새 revision을 사용한다.

M41의 GLB 파생본은 단위·축·export 기준으로만 참고한다.
M41의 외형·크기·궤도·포탑 구조를 적용하지 않는다.

## 형상

원본의 비율·크기·실루엣·바퀴 위치와 개수를 유지한다.
보닛·펜더·앞유리·오픈 캐빈·좌석·접힌 천막의 특징을 보존한다.
작은 디테일은 필요할 때만 단순화하고 변경 내용을 기록한다.
이미 충분히 단순하면 추가 단순화를 강제하지 않는다.

## Hierarchy

LV\_Kubelwagen\_ROOT
└─ HULL
├─ STEER\_FL
│  └─ WHEEL\_FL
├─ STEER\_FR
│  └─ WHEEL\_FR
├─ WHEEL\_RL
└─ WHEEL\_RR

- ROOT: 기존 원본의 차량 기준 원점을 유지한다.
- HULL: 차체·펜더·실내·등화류·천막 등 고정 부품을
  하나의 mesh로 통합한다.
- STEER\_FL/FR: 각각 전륜 중심에 배치한 조향용 Empty/Node.
- WHEEL\_\*: 타이어·휠·허브·트레드를 바퀴별 하나의 mesh로 통합한다.
- FL/FR/RL/RR은 차량 전방 기준 앞좌/앞우/뒤좌/뒤우다.
- 펜더와 차체 측 고정 부품은 WHEEL에 포함하지 않는다.
- 원본의 WHEEL\_\*가 Empty라면 해당 이름은 통합 wheel mesh에
  사용하고 중복 역할의 Empty는 남기지 않는다.
- 최종 구성은 8개 노드, 5개 mesh를 기준으로 한다.
  재질별 primitive 분할은 허용한다.

## 단위·축·피벗

최종 GLB:

- meter
- +X forward
- +Y up
- 차량 좌측 -Z, 우측 +Z

기본 자세에서 모든 노드의 local 축을 차량 축과 정렬한다.
STEER\_FL/FR은 local Y축 회전으로 좌우 조향한다.
WHEEL\_\*는 local Z축 회전으로 굴린다.

STEER\_FL/FR과 해당 WHEEL의 원점은 같은 휠 중심에 둔다.
따라서 전륜 WHEEL은 STEER에 대해 기본 local translation이 0이다.
후륜 WHEEL도 각 휠 중심을 원점으로 둔다.

Blender +Z up에서 GLB +Y up으로 변환할 때
geometry와 pivot에 동일한 변환을 적용한다.
음수 scale이나 좌우 반전용 불필요한 rotation을 남기지 않는다.
원본 크기를 유지하고 게임 표시 배율을 bake하지 않는다.

실제 킹핀 경사·캐스터·애커먼 조향·서스펜션은 구현하지 않는다.
휠 중심을 지나는 수직 조향축을 사용한다.

## 재질

가능하면 텍스처 없이 단순 base-color material을 사용한다.
재질 수를 줄이되 타이어·차체·좌석의 구분을 유지한다.
앞유리의 투명 표현은 원본 의도를 유지하고,
이를 바꾸어야 한다면 영향과 이유를 먼저 보고한다.
Normal/displacement/AO/baked-lighting texture는 추가하지 않는다.
정식 Art Direction을 확정하지 않는다.

## Export와 검증

오브젝트당 GLB 하나를 export하고 새 빈 scene에 재임포트한다.

확인 항목:

- hierarchy 및 이름, 8개 노드와 5개 mesh
- 원본 크기·기본 자세·부품 위치 유지
- meter, +X forward, +Y up
- FL/FR/RL/RR의 실제 위치
- ROOT·조향축·휠 중심 원점
- 정상 재질과 앞유리 표현, missing texture 없음
- negative scale 없음
- animation/skin/skeleton 없음

시험 회전:

1. STEER\_FL과 STEER\_FR을 각각 ±25도 회전한다.
   해당 전륜만 조향하고 차체·펜더·다른 바퀴가 고정되는지 확인한다.
2. 전륜이 조향된 상태에서 WHEEL\_FL/FR을 local Z축으로 굴린다.
   조향된 차축을 따라 회전하고 휠 중심이 이동하지 않는지 확인한다.
3. 후륜 WHEEL\_RL/RR의 local Z축 굴림을 확인한다.
4. 관찰된 타이어·펜더 간섭을 보고한다.
   시험 각도를 게임의 승인된 조향 한계로 간주하지 않는다.
   간섭 해소를 위해 원본 형상을 임의로 변경하지 않는다.
5. 시험 후 모든 저장 자산을 neutral pose로 복원한다.

기본 자세의 탑다운·측면·사선과
전륜 시험 조향 상태의 검증 이미지를 남긴다.
파생 Blender를 다시 열어 저장 상태를 확인한다.
원본 SHA-256을 작업 전후 비교한다.
기술 검증과 시각 검증을 별도로 보고한다.
